# Project 2 Phase 1: Structure from Motion (SfM)

This submission contains the implementation of Structure from Motion (SfM) to estimate 3D points and camera poses from 2D correspondences in images.

## Installation and Usage

To use the code in this folder, you need to have Python installed. It is recommended to use a virtual environment to manage dependencies.

### Setting up a Virtual Environment

1. Create a virtual environment:
    ```sh
    python -m venv venv
    ```

2. Activate the virtual environment:
    - On Windows:
        ```sh
        venv\Scripts\activate
        ```
    - On macOS and Linux:
        ```sh
        source venv/bin/activate
        ```

### Installing Dependencies

Install the required packages using `pip` and the provided `requirements.txt` file:

```sh
pip install -r requirements.txt
```

### Running the Code

Then run `Wrapper.py`:
```sh
python Wrapper.py
```
