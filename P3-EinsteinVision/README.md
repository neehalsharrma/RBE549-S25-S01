# P3: Einstein Vision (Phase 2)

The goal of this project is to develop a visualization system inspired by Tesla's dashboard, which intuitively represents how a robot perceives its environment. For Phase 2, the focus is on enhancing the features implemented in Phase 1 and adding advanced capabilities:

- **Lanes:** Detect and display different types of lanes (dashed, solid, white, yellow).
- **Vehicles:** Subclassify vehicles (e.g., sedan, SUV, truck) and identify their orientation. Represent them as respective 3D models.
- **Pedestrians:** Detect, locate, and estimate the pose of pedestrians in the scene.
- **Traffic Lights:** Indicate the presence, color, and arrow directions on traffic signals.
- **Road Signs:** Identify and display stop signs, speed limit signs, and road arrows using provided models and textures.
- **Objects:** Detect and represent additional objects like dustbins, traffic poles, cones, and cylinders.
- **Video Generation:** Generate annotated videos for YOLO, MiDaS, and TwinLiteNet outputs using `pyffmpeg`.

## Folder Structure

### `Networks/`

This folder contains all trained networks used for feature detection in the visualization system.

### `Results/`

This folder contains the results generated by the visualization system. It includes:

- Rendered images (`.png`) demonstrating each implemented feature.
- Rendered videos (`.mp4`) generated using `pyffmpeg`.

### `Assets/`

This folder contains all the static assets required for visualization, including:

- 3D models for vehicles, pedestrians, road signs, and additional objects.
- Textures and materials used for rendering.
- Configuration files for scene setup.

> [!WARNING]
> The assets in this folder have been modified to align with the current pipeline. Please review the folder and the `Blender.py` script if you wish to change this.

## How to Run on Ubuntu 22.04

1. **Setup Environment**  
   Create a Python virtual environment and install dependencies using *Blender's inbuilt Python interpreter*:

   ```sh
   /snap/blender/current/4.4/python/bin/python3.11 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

   **Note:** Replace `/snap/blender/current/4.4/python/bin/python3.11` with the path to Blender's Python interpreter on your system. You can locate it by running:

   ```sh
   which blender
   ```

   Then navigate to the `python/bin/` directory inside Blender's installation folder.

2. **Execution**  
   Run the visualization system by executing the `Wrapper.py` script to process the video and generate intermediate results:

   ```sh
   python Wrapper.py
   ```

   After processing, execute the `Blender.py` script with Blender's Python interpreter to render the 3D scenes:

   ```sh
   /snap/blender/current/4.4/python/bin/python3.11 Blender.py
   ```

   **Note:** Ensure that all required assets are in the `Assets/` folder and the trained networks are in the `Networks/` folder before running the scripts.

3. **Output**  
   The results will be saved in the `Results/` folder, including annotated videos, depth maps, and rendered 3D scenes.

4. **Troubleshooting**  
   If you encounter issues, verify the following:
   - All dependencies are installed in the virtual environment.
   - The paths to assets and networks are correctly configured in the `Wrapper.py` and `Blender.py` scripts.
   - Blender's Python interpreter is being used to execute the `Blender.py` script.
