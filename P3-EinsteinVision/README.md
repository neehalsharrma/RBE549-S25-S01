# P3: Einstein Vision (Phase 1)

The goal of this project is to develop a visualization system inspired by Tesla's dashboard, which intuitively represents how a robot perceives its environment. For Phase 1, the focus is on implementing the following features:

- **Lanes:** Detect and display different types of lanes (dashed, solid, white, yellow).
- **Vehicles:** Identify and represent vehicles as generic car shapes.
- **Pedestrians:** Detect and visualize pedestrians in the scene.
- **Traffic Lights:** Indicate the presence and color of traffic signals.
- **Road Signs:** Identify and display stop signs using provided models.

## Folder Structure

### `Networks/`

This folder contains all trained networks used for feature detection in the visualization system.

### `Results/`

This folder contains the results generated by the visualization system. It includes:

- Rendered images (`.png`) demonstrating each implemented feature:
  - `lanes.png` - Visualization of detected lanes.
  - `vehicles.png` - Visualization of detected vehicles.
  - `pedestrians.png` - Visualization of detected pedestrians.
  - `traffic_lights.png` - Visualization of detected traffic lights.
  - `stop_signs.png` - Visualization of detected stop signs.

- A rendered video (`visualization.mp4`) showing all features combined in a dynamic visualization.

### `Assets/`

This folder contains all the static assets required for visualization, including:

- 3D models for vehicles, pedestrians, and road signs.
- Textures and materials used for rendering.
- Configuration files for scene setup.

> [!WARNING]
> The assets in this folder have been modified to align with the current pipeline. Please review the folder and the `Blender.py` script if you wish to change this.

## How to Run on Ubuntu 22.04

1. **Setup Environment**  
   Create a Python virtual environment and install dependencies using *Blender's inbuilt Python interpreter*:

   ```sh
   /snap/blender/current/4.4/python/bin/python3.11 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

   **Note:** Replace `/snap/blender/current/2.93/python/bin/python3.9` with the path to Blender's Python interpreter on your system. You can locate it by running:

   ```sh
   which blender
   ```

   Then navigate to the `python/bin/` directory inside Blender's installation folder.
