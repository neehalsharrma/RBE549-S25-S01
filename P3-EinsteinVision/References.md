# References

## Models Used

1. **YOLOv11**  
   - Source: [YOLOv11 GitHub Repository](https://github.com/ultralytics/yolov5)  
   - Description: Used for object detection in video frames.

2. **MiDaS (ZoeDepth)**  
   - Source: [ZoeDepth GitHub Repository](https://github.com/isl-org/ZoeDepth)  
   - Description: Used for depth estimation in video frames. Combines relative and metric depth.

3. **TwinLiteNetPlus**  
   - Source: [TwinLiteNetPlus GitHub Repository](https://github.com/your-repo/TwinLiteNetPlus)  
   - Description: Used for additional frame processing tasks like semantic segmentation.

## Tools and Frameworks

1. **PyTorch**  
   - Source: [PyTorch Official Website](https://pytorch.org/)  
   - Description: Main framework for deep learning model implementation.

2. **OpenCV**  
   - Source: [OpenCV Official Website](https://opencv.org/)  
   - Description: Used for video frame processing and saving annotated outputs.

3. **Blender**  
   - Source: [Blender Official Website](https://www.blender.org/)  
   - Description: Used for rendering 3D scenes based on the generated JSON data.
